<ins>#Chat Room</ins>
Its a Basic Chat Room where you can Create, Join room (based on room number), and Chat in the chat room by entering your username and message.
Its a small project for me to learn how do sockets work and how do I implement them to express.

##How to install it
Run the following commands:
1.Use git clone to clone the repo:
```
git clone https://github.com/mentlly/Chat-Room
```
2.Go to backend folder inside Chat-Room folder:
```
cd Chat-Room
cd backend
```
3.Install Required node dependencies:
```
npm i express socket.io
```
4.Run `server.js`:
```
node server.js
```
